### 6 个典型使用场景

1. **销售数据分析**: 连接数据库 → AI 查询 → 生成图表 → AI 解读
2. **用户行为分析**: 连接数据库 → AI 查询 → 统计分析 → 洞察报告
3. **财务报表生成**: 连接数据库 → AI 查询 → 表格展示 → 导出 Excel
4. **库存监控**: 连接数据库 → AI 查询 → 仪表盘 → 异常告警
5. **数据问答**: 输入问题 → AI 转 SQL → 执行查询 → 返回结果
6. **数据报告**: 连接数据库 → AI 分析 → 生成报告 → 导出 PDF
